# Alternativas de ícone

Estes PNGs são opções de avaliação para a ISSUE-0006. `headphones-equalizer.png` foi aprovada e gerou o ícone de produção; as demais não são consumidas pelo build.

- `vinyl.png`: disco de vinil com trilha neon.
- `play-equalizer.png`: botão de reprodução com equalizador.
- `headphones-equalizer.png`: fones com equalizador.

Os formatos desktop, iOS e Android foram regenerados com `bun run tauri icon src-tauri/icons/candidates/headphones-equalizer.png --output src-tauri/icons`. Valide o launcher claro e escuro em aparelho antes da distribuição.
