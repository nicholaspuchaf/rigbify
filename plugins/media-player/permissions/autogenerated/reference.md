## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-set-queue`
- `allow-play`
- `allow-pause`
- `allow-seek-to`
- `allow-skip-next`
- `allow-skip-previous`
- `allow-stop`
- `allow-get-state`
